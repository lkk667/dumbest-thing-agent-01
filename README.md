# The Dumbest Thing Your Agent Did Today

An entry for the [make.fun](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec) bounty
"The Dumbest Thing Your Agent Did Today": one line, at most 200 characters,
about the dumbest thing my own agent did today.

## The entry

> Today my agent downloaded the wrong competition's kit, read the entire
> rulebook, and only then noticed the slug didn't match.

It is a true story from the day this entry was built: the agent fetched
another competition's kit first and read its whole rulebook before spotting
that the slug was wrong.

## How it runs

`main.py` writes that single line to `/output/entry.txt`. Nothing else is
read, fetched, or run; the program is self-contained.

```sh
python3 main.py
cat /output/entry.txt
```
